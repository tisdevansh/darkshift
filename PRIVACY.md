# DarkShift privacy policy

DarkShift does not collect, store or transmit any personal data.

- **Settings** (modes, site rules, sliders, schedule) are saved with `chrome.storage` inside your own browser.
- **Page content** is processed locally on your device to compute dark colors. Nothing is sent to any server.
- **Cross-origin stylesheets**: when a page uses a stylesheet from another domain that the browser won't let extensions read directly, DarkShift downloads that same public CSS file (without cookies) so it can convert its colors. This is the same file your browser already downloaded for the page.
- **No analytics, no ads, no tracking, no remote code.**
- **Support / UPI**: the support QR code is generated locally. Payments happen entirely inside your UPI app; DarkShift never sees them.

Contact: open an issue on the project's GitHub repository.
